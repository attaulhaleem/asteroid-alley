# Asteroid Alley

An endless space evasion game built in Unity 6. Navigate a spaceship through a dense asteroid field, survive as long as possible, and increase your score by covering distance.

## Controls

* **W, A, S, D / Arrow Keys** - Steer the spaceship
* **Spacebar (Hold)** - Warp Dash
* **Esc** - Pause Game

## Folder Structure

To help you navigate the project, the primary game files are organized within the `Assets` folder:

* `Assets/Scripts/` - Core C# game logic (managers, controllers, spawners).
* `Assets/Scenes/` - Contains the Main Menu and primary Game scene.
* `Assets/Prefabs/` - Reusable game objects (asteroids, explosions).
* `Assets/Models/` & `Assets/Materials/` - 3D assets, textures, and material settings.
* `Assets/Audio/` - Background music and sound effects.

## Development Setup

1. Clone this repository: `git clone https://github.com/attaulhaleem/asteroid-alley.git`
2. Open the project using **Unity 6**.
3. Navigate to `Assets/Scenes/` and open the main menu or game scene.
4. Press **Play** to test locally, or go to **File > Build Profiles** to export a build.
