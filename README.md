# Asteroid Alley

An endless space evasion game built in Unity 6. Navigate a spaceship through a dense asteroid field, survive as long as possible, and increase your score by covering distance. 

## Controls
* **W, A, S, D / Arrow Keys** - Steer the spaceship
* **Spacebar (Hold)** - Warp Dash
* **Esc** - Pause Game

## Development Setup
1. Clone this repository.
2. Open the project using **Unity 6**.
3. Open the main game scene in the editor.
4. Press **Play** to test locally, or go to **File > Build Profiles** to export a standalone build.
